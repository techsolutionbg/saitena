# Ограничен достъп за разрешени тестери

Saitena още не приема реални клиентски поръчки. Регистрацията, входът и
системните писма са разрешени единствено за предварително одобрени тестови
имейл адреси. Списъкът се пази само в защитената API конфигурация.

Потвърждението във формата означава участие в ограниченото тестване.
То не представлява сключване на договор за услуга или приемане на
непубликувани юридически документи. Не са активни поръчки, плащания,
домейн покупки или автоматично предоставяне на хостинг.

API записва точната версия чрез SHA256 на тази политика и release identity.
След публикуване на потвърдените юридически документи общата регистрация
ще изисква отделно одобрена политика и съответните договорни съгласия.

Този файл описва обхвата. Не е production deployment approval. Публикуването
изисква reviewed commit, CI, лично GitHub Environment и свежо root SSH одобрение.
