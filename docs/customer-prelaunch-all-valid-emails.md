# Предварително тестване с всеки валиден имейл

Тази версия позволява регистрация с всеки валиден имейл адрес. Изискват се
валидна парола, потвърждение на имейла и защитена клиентска сесия.
Акаунтите имат само клиентска роля. Административните права не се предоставят
чрез регистрацията.

Потвърждението във формата означава участие в предварителното тестване.
То не представлява сключване на договор за услуга или приемане на
непубликувани юридически документи. Поръчките, плащанията, домейн покупките
и автоматичното предоставяне на хостинг остават изключени.

API записва SHA256 на точната политика и release identity. Този документ
не променя вече приетата ограничена версия и не представлява deployment
approval. Активирането изисква нов exact manifest с
`registrationScope: all-valid-emails`, CI, лично GitHub Environment одобрение
и свежо лично root SSH одобрение. Старите политики и receipts се запазват.
