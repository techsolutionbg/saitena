# Portfolio hero redesign

The existing hero was replaced with a two-column server-rendered layout matching the user reference `Портфолио от модерни уеб проекти.png`: copy on the left, decorative laptop/mobile illustration on the right. On narrow screens the copy and primary CTA precede the illustration. The gallery, project pages, metadata, canonical URL and lower CTA remain unchanged.

Asset: `public/images/portfolio-hero-work-v1.webp`, 1100 × 1100 with transparency. Next.js Image supplies responsive sizes and reserves its aspect ratio. Existing content animation and reduced-motion support are retained.

The separate illustration was generated with the built-in image generation tool. HTML supplies all actual copy, controls and benefit labels.
