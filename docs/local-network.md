# Преглед в локалната мрежа

Първо стартирайте съществуващия dev сървър с `npm run dev` (127.0.0.1:3000). В отделен терминал в проекта изпълнете:

```powershell
npm run dev:lan
```

Командата показва адрес за другите устройства, например `http://192.168.1.213:3001`. Компютърът и двата процеса трябва да работят. Телефонът трябва да е в същата локална подмрежа, без изолация на клиентите в guest Wi-Fi.

`scripts/lan-preview.mjs` е отделен HTTP/WebSocket вход към съществуващия Next dev сървър. Не стартира втори Next процес, не използва отделен build и не прекъсва localhost прегледа. Fast Refresh използва `/_next/hmr`, както е в инсталираната версия на Next.js.

Помощникът се свързва само към избрания LAN IPv4 интерфейс, допуска клиенти от същата подмрежа и проверява Host и Origin. Само валидирани same-origin заявки се нормализират към localhost за Next.js. Не е общодостъпен forward proxy. Няма автоматични промени по защитната стена, DNS, production или хостинг платформата.

Изключват се виртуални, VPN и Tailscale интерфейси. При няколко физически интерфейса или за различен порт задайте преди стартиране:

```powershell
$env:SAITENA_LAN_HOST = "192.168.1.213"
$env:SAITENA_LAN_PORT = "3001"
npm run dev:lan
```

При зает порт помощникът приключва с грешка, без да спира други процеси. Ctrl+C в неговия терминал спира само мрежовия вход. При промяна на IP адреса той трябва да бъде стартиран отново.

При проблем проверете текущия адрес от изхода на командата, работещия upstream на порт 3000 и приложимите Windows Firewall правила за Node.js. Не е необходимо да отваряте порт в рутера.
