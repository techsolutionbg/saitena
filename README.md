# Saitena — „Ясно напред“

Избраният дизайн на публичния сайт на Saitena: обща светла и тъмна тема, адаптивна навигация и визуални форми. Next.js App Router, React и strict TypeScript. Проектът е локален прототип; няма production deployment или връзка със замразената хостинг платформа.

## Стартиране

```powershell
npm ci
npm run dev
```

Отворете [локалния сайт](http://127.0.0.1:3000). Сървърът слуша само на `127.0.0.1`. При зает порт използвайте `npm run dev -- --port 3100`, без да спирате чужд процес.

За работа с автоматично обновяване при запис оставете `npm run dev` да работи. Next.js Fast Refresh прилага промените в компонентите и стиловете в отворения браузър; когато е необходимо, извършва пълно презареждане. Не са нужни ръчно обновяване и нов build след всяка редакция. `npm run start` обслужва готовия production build и не следи файловете за промени.

## Форматиране на файл

```powershell
npm run format:file -- "src/components/plan-cards.tsx"
npm run format:check -- "src/components/plan-cards.tsx"
```

Командите използват локалния Prettier и `.prettierrc.json`. Подайте конкретен път; не се преформатира целият проект. Генерираните файлове и активите са изключени чрез `.prettierignore`.

За автоматично форматиране на избран файл при запис от всеки редактор оставете тази команда да работи в отделен терминал:

```powershell
npm run format:watch -- "src/components/plan-cards.tsx"
```

Следи само посочения файл, включително при запис чрез временен файл и преименуване. Синтактична грешка се показва в терминала и файлът не се презаписва; след поправката следенето продължава. Собственият запис на formatter-а не предизвиква безкраен цикъл. Ctrl+C спира следенето.

Във VS Code/Cursor проектната `.vscode/settings.json` включва Format on Save с разширението **Prettier – Code formatter** (`esbenp.prettier-vscode`). То е препоръчано в `.vscode/extensions.json` и трябва да бъде инсталирано/активно в редактора. Няма промени в глобалните настройки. Има и задача **Saitena: Форматирай текущия файл**, достъпна през **Tasks: Run Task**. Използвайте editor Format on Save или watcher за съответния файл.

Подробности: [Prettier CLI](https://prettier.io/docs/cli) и [официалната интеграция за VS Code](https://github.com/prettier/prettier-vscode).

## Избрана посока

- Единствен дизайн: „Ясно напред“. Селекторът и страниците на другите две концепции са премахнати.
- Страниците вече са на основните маршрути: `/`, `/uslugi`, `/planove`, `/portfolio`, `/za-nas`, `/kontakti`, `/zapitvane`, `/vuprosi`, `/blog`, `/pravni/…` и `/karta-na-saita`.
- Старите адреси `/concepts/clarity/…` пренасочват към съответните нови страници. Непубликуваните английски адреси и премахнатите други концепции връщат 404.
- Светла тема по подразбиране; тъмна тема чрез истински checkbox. Изборът се запазва локално, синхронизира се между отворени раздели и се прилага преди първото изобразяване при презареждане.
- На мобилен телефон и таблет менюто отваря анимиран modal sidebar с икони, скролиращи връзки и постоянно видим превключвател за темата. Escape, затваряне с бутон/фон, връщане на фокуса, keyboard loop и reduced motion са предвидени.
- Параграфи: **18 px / 400**. Всички реални h1–h6: **24 px / 600**, без различни мобилни размери. Интерфейсните икони са 26–32 px.

Актуалните правила и техническите решения са в [docs/design-system.md](docs/design-system.md). [docs/stage-1.md](docs/stage-1.md) пази историческото предложение от етап 1 и не описва актуалния избор между дизайни.

## Основни файлове

| Файл                              | Отговорност                                                                           |
| --------------------------------- | ------------------------------------------------------------------------------------- |
| `src/app/globals.css`             | Единни цветови и типографски променливи, компоненти и адаптивни правила               |
| `src/app/artwork.css`             | Оригинални илюстративни сайт макети; техният декоративен текст не е реално съдържание |
| `src/app/layout.tsx`              | Общи header/footer, език, метаданни и начално прилагане на темата                     |
| `src/app/[...slug]/page.tsx`      | Server-rendered вътрешни страници                                                     |
| `src/components/header.tsx`       | Desktop навигация и достъпен мобилен sidebar                                          |
| `src/components/theme-toggle.tsx` | Checkbox превключвател и синхронизация на темата                                      |
| `src/components/icons.tsx`        | Общи SVG икони                                                                        |
| `src/components/site.tsx`         | Начална страница, планове, процес, FAQ, CTA и футър                                   |
| `src/lib/navigation.ts`           | Основни, мобилни и правни връзки                                                      |
| `src/lib/content.ts`              | Потвърден обхват на START, примерни проекти, FAQ и статии                             |

Българският е основен език. Английският остава архитектурно подготвен в `src/lib/i18n.ts`, без празни преведени страници.

## Граници

За публичните контакти във футъра попълнете `.env.example` в собствен `.env.local`/`.env` според [настройките за контакт](docs/contact-details.md).

За локално изпращане от контактната форма през Mailpit вижте [локалната тестова поща](docs/local-contact-mail.md). Стартиране: `npm run mail:up`; преглед на писмата: <http://127.0.0.1:18025>.

START остава 50 €/месец без първоначална такса и с подадения обхват. MEDIUM/PREMIUM са концептуални. Формите не изпращат и не записват данни; запазва се единствено изборът на тема в localStorage. Няма клиентски профили, поръчки, плащания, административен панел, аналитика или реално вграден Maps. Правните страници са структурни макети. Примерните проекти са обозначени като илюстрации.

Всички страници остават `noindex, nofollow`; `robots.txt` забранява обхождане до одобрен публичен етап. Няма промени по хостинг, DNS, Cloudflare, база данни, поддомейни или production.

## Проверки

За различни въпроси и отговори на отделните страници използвайте общия [FAQ компонент](docs/faq-component.md), който приема собствен списък чрез `items`.

```powershell
npm run typecheck
npm run build
```

Това са локални проверки и не публикуват сайта. В среда с Windows sandbox build може да изисква локално разрешение за генерираните маршрутни директории в `.next`.
