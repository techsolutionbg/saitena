# Saitena — етап 1: структура и дизайн

Локален Next.js App Router проект с три визуално различни, адаптивни прототипа. Това е дизайн преглед за одобрение, а не завършен функционален или публикуван сайт.

## Стартиране

Изисква Node.js 20.9+ и npm. Версиите са фиксирани в `package.json` и `package-lock.json`.

```powershell
npm ci
npm run dev
```

Отворете [прегледа на концепциите](http://127.0.0.1:3000). Сървърът слуша само на loopback адреса. При зает порт използвайте `npm run dev -- --port 3100`, без да спирате чужд процес.

| Desktop                                                          | Mobile в интерактивна рамка                     |
| ---------------------------------------------------------------- | ----------------------------------------------- |
| [01 — Ясно напред](http://127.0.0.1:3000/concepts/clarity)       | [390 px](http://127.0.0.1:3000/preview/clarity) |
| [02 — С грижа за идеите](http://127.0.0.1:3000/concepts/atelier) | [390 px](http://127.0.0.1:3000/preview/atelier) |
| [03 — Дигитален импулс](http://127.0.0.1:3000/concepts/pulse)    | [390 px](http://127.0.0.1:3000/preview/pulse)   |

Всяка концепция включва начална, услуга, планове, портфолио с филтри и подробни проекти, за нас, контакти, запитване за сайт, FAQ, блог с примерни статии, HTML карта и структурни макети на правните страници.

## Решения и граници

Пълното предложение за маршрути, дизайн, SEO/GEO, планове и решения за одобрение е в [docs/stage-1.md](docs/stage-1.md).

- **Препоръчана посока:** 01 „Ясно напред“.
- **START:** 50 €/месец без първоначална такса; потвърденият обхват е запазен.
- **MEDIUM/PREMIUM:** концептуални; няма окончателни цени или договорни условия.
- Формите проверяват полетата само в браузъра и показват демонстрационен статус. Няма изпращане, записване, имейл интеграция или API за запитвания.
- Примерните проекти са оригинални CSS илюстрации, ясно обозначени като концепции. Няма измислени клиенти, резултати или отзиви.
- Правните страници са макети на структурата, не готови правни текстове.
- Няма GA4, Maps, тракери, външни шрифтови заявки, профили, поръчки, плащания, административен панел или база данни.
- Всички prototype маршрути са `noindex, nofollow`; `robots.txt` забранява обхождане. Не е публикуван production XML sitemap. Това е умишлена защита на дизайн вариантите, не окончателната SEO конфигурация.
- Няма връзка, промени или deployment към замразената хостинг платформа, инфраструктура, DNS, Cloudflare или поддомейни.

## Организация

```text
src/app/                         App Router, метаданни и адаптивни стилове
src/app/concepts/[concept]/      Изолирани прототипи на трите концепции
src/app/preview/[concept]/       Интерактивна мобилна рамка
src/components/                  Общи компоненти, CSS илюстрации и визуални форми
src/lib/content.ts               Българско съдържание и модел на страниците
src/lib/i18n.ts                  Подготовка на locale и преведени маршрути
docs/stage-1.md                  Архитектура и дизайн предложение
```

Страниците и основното съдържание се рендерират на сървъра. Клиентски компоненти се използват за менюто, превключването на концепции, филтрите и визуалната проверка на формите. Стилизиране: CSS variables, Grid, Flexbox, media/container units и споделени компоненти; без допълнителна UI библиотека. Шрифтовете с кирилица се сервират локално чрез Fontsource.

Английският е подготвен като locale и маршрутна карта, но няма частично преведени страници или неработещ езиков превключвател.

## Проверки

```powershell
npm run typecheck
npm run build
```

`build` е локална компилация и не публикува никъде. Проектът няма deployment скрипт. Няма добавена тестова инфраструктура само за визуалния етап. Резултатите и ограниченията на проверките са записани в документа за етапа.

Пълната функционална разработка изисква одобрение на следващия етап. Не свързвайте формите, аналитика или външни услуги като част от дизайн прегледа.
