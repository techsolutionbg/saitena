# Компоненти

Компонентите са групирани според предназначението им. CSS модулите стоят до компонентите, които ги използват.

| Папка            | Съдържание                                                                   |
| ---------------- | ---------------------------------------------------------------------------- |
| `layout/`        | Header, Footer и Brand                                                       |
| `appearance/`    | Настройки на изгледа и превключване на темата                                |
| `ui/`            | Икони, бутони, заглавия, въвеждащи блокове, пояснения и ScrollReveal         |
| `shared/`        | CTA и процес, използвани в повече от една страница                           |
| `home/`          | Начална страница, hero, вълни, предимства и съдържателни секции              |
| `portfolio/`     | Hero, галерия с филтри и CTA на портфолиото                                  |
| `pricing/`       | Страница с цени, планове, индивидуална оферта, сигурност и мобилно сравнение |
| `contact/`       | Контактна форма, потвърждение, бързи връзки и карта                          |
| `faq/`           | Преизползваем FAQ, начална секция и каталог с въпроси                        |
| `illustrations/` | Декоративни макети на сайтове                                                |
| `pages/`         | Съставяне на останалите вътрешни страници                                    |

Импортирайте компонентите директно от конкретния модул, например `@/components/portfolio/portfolio-gallery`. Не използваме общи barrel файлове, които смесват server и client компоненти.

Преди смесените `site.tsx` и `interactive.tsx` са разделени на отделни модули за Home, Footer, ButtonLink, SectionHeading, PageIntro, Process, CTA, PortfolioGallery и InquiryForm. Директивите `use client` остават само в модулите, които ги изискват.
